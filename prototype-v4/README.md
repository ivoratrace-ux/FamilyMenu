# Прототип v4 «Семейное меню»

HTML-прототип, на стилях которого построен интерфейс v7 (цвета, шрифты, отступы, компоненты).

- `index.html` — собранный прототип, открывается в браузере без сервера.
- Исходники: `pre.txt` (разметка и стили), `base.css.txt`, `extra.css.txt`, `data.js` (рецепты и справочник), `art.js` (иллюстрации), `cook.js` (режим готовки), `app.js`, `shell.js`, `v4.js`.
- Пересборка: `python3 build4.py` — склеивает исходники в `index.html`.

Данные и цены — снимок 20–21.10.2026, без обращений к серверу.
