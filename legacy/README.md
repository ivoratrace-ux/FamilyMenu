# Семейное меню — прототип

Кликабельный прототип мобильного приложения: меню на неделю для семьи, рецепты с пошаговыми картинками и таймерами, список покупок с ценами ВкусВилла и Яндекс Лавки, подсчёт калорий.

## Запуск

Сборка не нужна — это статическая страница.

- Локально: откройте `index.html` в браузере или запустите `npx serve .` в папке проекта.
- На GitHub Pages: Settings → Pages → Source: «Deploy from a branch», ветка `main`, папка `/ (root)`. Через минуту прототип будет доступен по адресу `https://<логин>.github.io/<репозиторий>/`.

## Структура

| Файл | Что внутри |
|---|---|
| `index.html` | Точка входа |
| `src/styles.css` | Стили и цветовые токены (светлая и тёмная тема) |
| `src/data.js` | Продукты (КБЖУ, цены ВкусВилла и Лавки), 144 рецепта, аллергены, типы питания, акции |
| `src/art.js` | Генератор иллюстраций блюд (SVG) |
| `src/cook.js` | Шаги рецептов: картинки действий, таймеры, ссылки на магазины, распознавание еды «1 банан» → ккал |
| `src/app.js` | Логика: подбор меню, замены, перетаскивание, список покупок, калории, экраны |
| `src/shell.js` | Вводные слайды, вход, онбординг-квиз, боковое меню, акции и сравнение цен |

## Ограничения прототипа

- Вход по телефону — имитация: СМС не отправляется, подходит любой код из 4 цифр.
- Данные хранятся в `localStorage` браузера.
- Цены — снимок на 20–21.10.2026 (ВкусВилл и Яндекс Лавка, Москва), для других городов пересчёт по коэффициенту.
- Распознавание незнакомых продуктов через Claude работает только внутри артефакта Claude; в отдельном хостинге используется встроенный словарь (~130 продуктов).
